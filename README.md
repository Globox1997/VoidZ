# VoidZ
VoidZ is an addon for the AdventureZ mod.

### Installation
VoidZ is a mod built for both the [Fabric Loader](https://fabricmc.net/) and [NeoForge](https://neoforged.net/).

- **Fabric:** requires [Fabric API](https://www.curseforge.com/minecraft/mc-mods/fabric-api), [Cloth Config API](https://www.curseforge.com/minecraft/mc-mods/cloth-config) and [AdventureZ](https://www.curseforge.com/minecraft/mc-mods/adventurez) to be installed separately.
- **NeoForge:** requires [Cloth Config API](https://www.curseforge.com/minecraft/mc-mods/cloth-config) and [AdventureZ](https://www.curseforge.com/minecraft/mc-mods/adventurez) to be installed separately.
